# 产品需求规格说明书 (PRD: Product Requirements Document)

## 1. 产品背景与定位

在工业工程规划、工艺热工设计、新能源储能评估以及企业商业财务测算中，工程师与决策者经常需要处理大篇幅的非结构化材料（技术方案、招标文件、会议纪要等），提取关键指标并进行多层级复杂计算。

现有的通用大模型在执行此类任务时存在两大致命短板：
1. **数值计算幻觉**：LLM 自身缺乏精确浮点计算能力，多步公式推导极易出现算术错误；
2. **流程失控与跳步**：缺乏强类型状态机约束，经常跳过量纲换算、漏掉离散选型步长规整或违背工程常理。

**本项目定位**：构建一个工业级、强类型、通用的智能计算 Skill。该 Skill 能够作为核心引擎被上层大 Skill 调度，或直接供工程师交互使用；具备类似 `/工控院/skills/calculate/输入输出.xlsx` 的输入即计算能力，支持全向正反解推导，并提供高度隔离的声明式场景自迭代机制。

## 2. 核心功能需求清单 (Functional Requirements)

### FR-1: 多模态非结构化材料摄取与参数规整化
- **输入支持**：自然语言文本段落、技术文件摘录、PDF 文本、结构化或半结构化表格。
- **槽位识别**：AI 从原始材料中精准捕获业务参数及其工况上下文。
- **量纲对齐**：支持工业常用单位自动转换为系统标准量纲（如：将“15公斤蒸汽”自动换算为 `1.47 MPa`，将“100吨/小时”对齐为 `100.0 t/h`，将“2.2亿元”对齐为 `22000.0 万元`）。
- **缺参交互澄清**：若推导所需的核心独立自变量缺失，系统必须生成精准的提问表单，向用户或调用方索取，严禁随意胡乱捏造默认值。

### FR-2: 参照 Excel 标杆表格的联动多层级计算与报表交付
- **标杆对照**：完整覆盖类似 `输入输出.xlsx` 中的工业全流程计算能力：
  1. **物性参数层**：水蒸气热力学查表计算（焓值、比容等）、熔盐物性多项式拟合计算（密度、比热、粘度、导热系数）；
  2. **工艺能量层**：热平衡吸放热量、连续制热/储热理论功率计算；
  3. **设备选型层**：电加热器 5MW 步长向上取整、变压器标准型谱 (MVA) 档位匹配；
  4. **经济概算层**：分项工程造价计算、建安工程费、独立费用费率联动、动态投资与税费计算。
- **输出交付能力**：
  - **结构化输出**：标准格式 JSON，包含完整的输入参量、物性参量、中间状态、设备选型与最终造价指标；
  - **报表文件交付**：在磁盘上自动回填并生成保留原生计算公式的 Excel (`.xlsx`) 文件，支持离线调参；生成 Markdown 格式的执行摘要。

### FR-3: 极高灵活性的全向代数与多层级反向逆解 (Bidirectional Solving)
- **代数符号反解**：对于任意代数方程（例如 $a + b + c = d$），系统必须支持已知任意 3 个量反解第 4 个量（如已知 $a, b, d$ 自动求解 $c = d - a - b$）。
- **全流程跨层逆解**：支持从最末端经济/投资指标反推前端工艺参数（例如：“已知动态总投资上限为 2.2 亿元，反求在 8 小时谷电时长下的最大供汽流量”）。
- **离散规则逆解**：对于包含 `ROUNDUP` 取整、阶梯单价等非光滑离散函数的场景，系统利用单调性区间感知二分搜索算法实现穿透反解。

### FR-4: 声明式场景包与 AI 自迭代机制 (Extensibility & Self-Evolution)
- **场景扩展性**：支持不同工程或商业场景（如“熔盐储热”、“压缩空气储能”、“电化学储能”、“企业财务利润测算”等）的灵活扩展。
- **防“史山”代码隔离**：所有场景必须封装在独立的 `scenarios/<scenario_id>/` 目录下，包含元数据、方程、离散规则与基准测试用例。禁止在通用引擎内堆砌临时业务逻辑。
- **AI 自迭代规范手册**：提供详细的《开发规范说明书》与自动化沙盒，约束 AI 按照标准步骤扩展公式，测试全绿后方准入生效。

### FR-5: 模块化与上层大 Skill 契约集成 (Orchestration Contract)
- 提供自描述、标准化的 Python API 与 REST/JSON 交互接口。
- 支持大 Skill 进行场景发现 (`list_scenarios`)、规格获取 (`get_scenario_spec`)、核心计算执行 (`calculate`) 以及变更派发。

## 3. 非功能性需求 (Non-Functional Requirements)

1. **计算确定性 (100% Deterministic)**：所有数学运算均由底层确定性引擎执行，LLM 绝不直接运算浮点数，杜绝算术幻觉。
2. **状态机执行强约束 (Non-Skipping FSM)**：严格执行 S0~S8 单向状态流转，必须在满足前置守卫与后置不变量后方可推进。
3. **计算性能 (High Performance)**：单次前向标准计算耗时不超过 100ms；反向单变量二分搜索迭代反解耗时不超过 500ms。
4. **异常容错与审计可追溯**：每个状态的执行轨迹和耗时均需记录到 `fsm_trace`，计算异常给出根因诊断信息（如物性越界、换热夹点温度交叉、矩阵奇异）。

## 4. 验收标准 (Acceptance Criteria)

- [ ] **AC-1**: 能够接收自然语言材料，准确识别出蒸汽压力、温度、流量等核心参数，并自动完成单位换算。
- [ ] **AC-2**: 输入 `输入输出.xlsx` 中的基准工况参数，输出的各项物性值、功率、选型规格、静态投资、动态投资与 Excel 原表数值偏差 $< 0.1\%$。
- [ ] **AC-3**: 输入公式 $a+b+c=d$ 及任意 3 个已知量，能够准确求解剩余 1 个量；输入总投资上限能够反算出对应的最大供汽流量。
- [ ] **AC-4**: 新增或修改场景时，核心 `engine/` 代码未受任何修改，新场景在沙盒中通过 100% 回归测试。
- [ ] **AC-5**: 成功生成符合标杆格式的 `.xlsx` 报表文件并返回给调用方。
