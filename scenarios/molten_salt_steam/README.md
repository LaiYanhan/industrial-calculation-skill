# 场景说明: 谷电熔盐储热供蒸汽全流程计算

本场景包对应项目根目录下的 **`输入输出.xlsx`** 标杆工程案例。

## 工艺背景
谷电熔盐储热供蒸汽系统利用夜间低谷电价时段（如 8 小时），驱动电加热器或高温热泵加热熔盐（HITEC 熔盐，温区 190℃ ~ 390℃）并储存于储热罐中。白天通过蒸汽发生系统 (SGS) 释放热量，连续供应工业所需的高品质饱和或过热蒸汽（如 8 小时，1.5MPa，200℃，100t/h）。

## 核心阶段与文件映射
1. `manifest.yaml`: 规范蒸汽压力、温度、流量、给水状态及设备效率；
2. `equations.py`: SGS 功率、制热量、电加热器功率、储热量及熔盐用量连续计算；
3. `sizing_rules.json`: 电加热器 5MW 步长规整、变压器容量标准档位匹配；
4. `costing_rules.yaml`: 设备阶梯单价与工程概算费率联动；
5. `benchmarks.json`: 100t/h 标杆工况正向与反向投资限额反解测试集；
6. `spec.py`: 场景组装适配器类。
