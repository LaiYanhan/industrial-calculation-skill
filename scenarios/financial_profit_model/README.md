# 场景说明: 企业商业财务利润测算模型

本场景展示智能计算通用状态机在**纯商业财务与经营测算领域**的应用。

## 业务背景
企业在制定年度预算或新产品定价策略时，需根据预计单价、销量、BOM 可变成本、固定研发管销费用、固定资产折旧及利息支出，测算营收、毛利率、EBITDA 及税后净利润，或反向测算保本销量。

## 核心阶段与文件映射
1. `manifest.yaml`: 规范单价、销量、成本、折旧及税率元数据；
2. `equations.py`: 营收、毛利、EBITDA、EBIT、净利润闭环代数方程；
3. `sizing_rules.json`: 销量整件取整、超额累进与小微优惠税率；
4. `benchmarks.json`: 标准正向利润核算与目标利润反推销量测试集；
5. `spec.py`: 场景组装适配器类。
